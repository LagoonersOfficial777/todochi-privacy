# Privacy Policy — Todochi (Test Build)

**Effective Date:** July 22, 2026

This is a preliminary test version of Todochi, developed by Lagooners, 
used solely for closed testing purposes prior to public release.

## Information We Collect

This test build does not collect, store, or transmit any personal data.

Specifically, this app does **not**:
- Collect your name, email, or contact information
- Access your camera, microphone, or location
- Use analytics, advertising, or tracking services
- Require an account or login
- Send any data to external servers

Any content you enter (such as sample reminders) is stored only 
temporarily on your device and is not transmitted anywhere.

## Permissions

This test build may request notification permissions solely to 
demonstrate local reminder functionality. No data associated with 
this permission is collected or shared.

## Changes to This App

This is an early test version. The final public release of Todochi 
may include additional features and services (such as cloud sync or 
subscription purchases), and this Privacy Policy will be updated 
accordingly before that version is released.
